# Extract retention indices and their provenance

Extract retention indices and their provenance

## Usage

``` r
retention_indices(x, which = NULL, phase = NULL)
```

## Arguments

- x:

  A GCMSlibrary object.

- which:

  Spectrum indices.

- phase:

  Optional DB1, DB5, DBWAX or unknown phase filter.

## Value

A long data frame with one row per recorded index.
